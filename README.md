# Student Result Management System (C++)

This is a simple console-based C++ project that calculates
student results based on marks entered by the user.

## Features
- Accepts multiple students
- Calculates total and average marks
- Displays grade based on average

## Concepts Used
- Arrays
- Loops
- Conditional statements
- Input / Output

## How to Run
g++ studentmanagment.cpp
./a
